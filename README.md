# AdriExpress

Projeto acadêmico da disciplina Front-end 1 de ADS"Análise e Desenvolvimento de Sistemas do IFSC". Somente a interface:em HTML e CSS, sem funcionalidades reais.

## Páginas

- `Abas/index.html`: destaque da loja, descrição, galeria com dez produtos e contato.
- `Abas/cadastro.html`: cadastro com validações nativas do HTML.
- `Abas/login.html`: formulário de acesso e link para cadastro.
- `Abas/perfil.html`: edição de dados e tabela de pedidos.
- `Abas/loja.html`: catálogo com filtros visuais e dez produtos.
- `Abas/relatorios.html`: relatórios de clientes e compras, com versão para impressão.
- `Abas/Contato.html`: página de contato com informações e formulário.

## Estrutura

- `Abas/`: páginas HTML.
- `CSS/`: estilos compartilhados em `base.css` e uma folha própria para cada página.
- `Imgs/`: imagens do catálogo e da página inicial.
